04 • Agent-Safe Metadata Design Standardizing Frontmatter Types & AGENTS.md Contracts

Designing Agent-Safe YAML Property Schemas

A .base database is only as sharp as the YAML frontmatter underneath it. Without an explicit schema contract, AI agents drift across synonyms—writing dueDate on Monday and due_date on Tuesday—silently splitting one column into sparse fragments.

Schema-First Precision: Standardized YAML frontmatter headers act as color-coded keys that slot every atomic Markdown note cleanly into your relational .base Table and Cards layouts.

1. Obsidian's 6 Native Property Types (Backed by .obsidian/types.json)

UI Type types.json ID Exact Agent YAML Syntax Agent Guardrail & Base Filter Behavior
Text "text" status: "active"  |  owner: "[[Ada]]" Always quote wikilinks ("[[Ada]]")! Unquoted [[Ada]] parses as a nested YAML array.
Number "number" priority: 1  |  effort_hrs: 4.5 Emit bare numbers without quotes so <, >, and Average summaries compute numerically.
Checkbox "checkbox" shipped: false Use lowercase YAML booleans (true / false), never "yes" or "True" strings.
Date "date" due: 2026-12-15 Strict ISO-8601 YYYY-MM-DD only; powers date(due) < today() in .base formulas.
Date & time "datetime" reviewed_at: 2026-11-12T14:30:00 ISO-8601 timestamp (YYYY-MM-DDTHH:mm:ss); ideal for meeting logs and sync stamps.
List / Tags "multitext" / "tags" tags: [project, q4] Always emit a YAML array even for single items ([q4]) so .contains() never fails.

05 • Native .base Databases & Formulas Complete YAML Query Anatomy & Multi-View Dashboards

Authoring Native .base Files & Formulas With AI

Every Obsidian .base file is a declarative YAML document with four top-level blocks: global filters, calculated formulas, column properties labels, and a views array defining Table and Cards tabs.

1. Production roadmap.base Anatomy (Copy-Paste Reference)

filters:
  and:
    - or: [file.inFolder("Projects"), file.inFolder("Specs")]
    - 'status != "archived"'
formulas:
  days_left: 'if(due, (date(due) - today()).days, "")'
  sla_badge: 'if(status == "done", "Shipped", if(date(due) < today(), "OVERDUE", "On Track"))'
properties:
  file.name: { displayName: "Deliverable" }
  status: { displayName: "Stage" }
  formula.sla_badge: { displayName: "SLA Health" }
views:
  - type: table
    name: "Active Execution Table"
    limit: 50
    groupBy: { property: status, direction: ASC }
    order: [file.name, status, priority, owner, due, formula.sla_badge, formula.days_left]
  - type: cards
    name: "Blocked & Urgent Cards"
    filters:
      or: ['status == "blocked"', 'priority == 1']
    order: [file.name, owner, due, formula.sla_badge]

2. High-Value Built-In .base Functions Agents Should Use

File Context

file.inFolder("Specs"), file.hasTag("q4"), file.hasLink("Roadmap"), file.name, and file.mtime filter notes without redundant YAML keys.

Date & Math

Compare date(due) < today(), inspect now(), format decimals via .toFixed(2), and branch cleanly with if(cond, a, b).

List & Embeds

Test multi-value lists via tags.contains("urgent"). Embed any view inside Markdown using ![[roadmap.base#Blocked & Urgent Cards]]!

3. Color-Coded Prompt Anatomy: Generating Multi-View .base Cockpits

[SCHEMA READ] First read AGENTS.md and .obsidian/types.json to verify exact property names and types. [DATASET SCOPE] Create Dashboards/engineering-radar.base filtering notes where file.inFolder("Specs") and status != "archived". [FORMULAS] Add two formulas: age_days from file.ctime and risk_flag flagging items where priority == 1 and status == "blocked". 06 • Open JSON Canvas 1.0 & Coordinate Math Generating Non-Overlapping Spatial Blueprints With AI

Mastering Open JSON Canvas (.canvas) & Grid Math

Published under an open specification at jsoncanvas.org, every .canvas file is a standard JSON object with two arrays: nodes[] (ordered back-to-front by z-index) and edges[]. Deterministic grid math turns messy guesses into crisp blueprints.

1. Exact JSON Canvas 1.0 Schema Reference

{
  "nodes": [
    { "id": "grp-core-0000001", "type": "group",
      "label": "Core Services", "color": "4",
      "x": -40, "y": -48, "width": 720, "height": 268 },
    { "id": "nd-auth-00000001", "type": "file",
      "file": "Specs/auth-gateway.md",
      "subpath": "#Token Flow", "color": "5",
      "x": 0, "y": 0, "width": 300, "height": 180 },
    { "id": "nd-note-002", "type": "text", "color": "2",
      "text": "### Rate Limit\n1,200 req/min per key",
      "x": 380, "y": 0, "width": 260, "height": 180 }
  ],
  "edges": [
    { "id": "ed-auth-rate-001",
      "fromNode": "nd-auth-00000001", "fromSide": "right",
      "toNode": "nd-note-002", "toSide": "left",
      "toEnd": "arrow", "label": "enforces" }
  ]
}
4 Official Node Types (nodes[])
  • "group": Visual container (label). List groups FIRST in nodes[] so they render behind cards!
  • "file": Relative vault path ("Specs/auth.md") + optional heading subpath.
  • "text": Standalone Markdown card (text with \n).
  • "link": Live external URL card (url).
Obsidian Preset Palette (color)

Strings "1" Red (blockers), "2" Orange (warnings), "3" Yellow, "4" Green (done), "5" Cyan (APIs), "6" Purple (specs)—or hex "#d97706".

Clean Orthogonal Edges (edges[])

Always set fromSide & toSide: left-to-right flows wire "right" → "left"; top-down trees wire "bottom" → "top".

2. Anti-Overlap Coordinate Grid Math (Never Stack Nodes at 0, 0!)

When prompted vaguely to "make a canvas," LLMs often guess overlapping coordinates. Hand your agent these four deterministic layout equations:

Layout Element Deterministic Integer Formula Why It Guarantees Readability
Card Slot (x, y) x = col * 380  |  y = row * 240 For 300×180 cards, leaves an 80px horizontal gutter for edge labels and a 60px vertical gutter.
Height by Lines height = max(160, 90 + lines * 24) Prevents vertical scrollbars on multi-bullet text cards at overview zoom.
Group Bounds gx = min_x - 40, gy = min_y - 48
gw = (max_r - min_x) + 80		 Wraps child cards with 40px side padding and 48px top clearance for the group title bar.
Integer Pixels int(round(coord)) (no floats!) JSON Canvas 1.0 requires strict integer pixel values for x, y, width, and height.
Strict JSON Hygiene: Zero Comments & Zero Trailing Commas
Obsidian's .canvas parser enforces strict RFC 8259 JSON. A single // comment or trailing comma renders an empty canvas—always validate with python3 -m json.tool before saving.

When to use: You have 30+ messy meeting notes, ADRs, or research clippings in a folder and need operational clarity fast.

  1. Audit & Normalize: Ask Claude Desktop or Antigravity to scan Projects/Q4/*.md and backfill missing status, owner, priority, and ISO due YAML frontmatter per AGENTS.md.

When to use: You prefer brainstorming visually—dragging out 12 rough text cards and arrows on brainstorm.canvas during a whiteboard session.

  1. Read Visual Topology: Point Antigravity at brainstorm.canvas. It parses nodes[], parent group bounds, and edges[] to infer hierarchy and dependencies!

09 • Automated Verification Collision Checks & .obsidian/types.json Registry

Validation Scripts & Layout Polish in Antigravity

Professional agent workflows never trust raw LLM JSON blindly. Adding a tiny 25-line Python check inside Antigravity Desktop catches broken file paths, duplicate IDs, float coordinates, and overlapping cards in milliseconds before you even switch windows to Obsidian.

1. The 25-Line validate_canvas.py Pre-Flight Script

Save this helper in a local _scripts/validate_canvas.py file (or let Antigravity run it automatically after generating any .canvas board): 

import json, sys, pathlib

vault = pathlib.Path(sys.argv[1]).resolve()
canvas_path = pathlib.Path(sys.argv[2]).resolve()
data = json.loads(canvas_path.read_text(encoding="utf-8"))  # Fails fast on trailing commas!

nodes, edges = data.get("nodes", []), data.get("edges", [])
ids = [n["id"] for n in nodes] + [e["id"] for e in edges]
assert len(ids) == len(set(ids)), "Duplicate node/edge ID detected!"

cards = [n for n in nodes if n["type"] != "group"]
for n in nodes:
    for k in ("x", "y", "width", "height"):
        assert isinstance(n[k], int), f"Node {n['id']} {k}={n[k]} must be integer!"
    if n["type"] == "file":
        assert (vault / n["file"]).exists(), f"Missing vault file: {n['file']}"

for i, a in enumerate(cards):
    for b in cards[i + 1:]:
        overlap = (a["x"] < b["x"] + b["width"] and a["x"] + a["width"] > b["x"] and
                   a["y"] < b["y"] + b["height"] and a["y"] + a["height"] > b["y"])
        assert not overlap, f"Bounding-box collision between {a['id']} and {b['id']}!"
print(f"OK: {len(nodes)} nodes, {len(edges)} edges, 0 broken paths, 0 card overlaps.")

The Fix: Have Antigravity inspect and update .obsidian/types.json whenever you add a new canonical field to AGENTS.md. Locking "due": "date" and "priority": "number" ensures native calendar pickers, checkboxes, and .base column summaries behave deterministically across your entire vault.

11 • Troubleshooting Clinic & Pre-Flight 7 Common Failure Modes & 6-Point Launch Checklist

Troubleshooting Clinic & Pre-Flight Checklist

Nearly every broken .base column or unreadable .canvas board traces back to one of seven syntax mismatches. Keep this diagnostic table handy for ten-second fixes.

Top 7 Issues & 10-Second Fixes

Symptom in Obsidian Root Cause on Disk 10-Second Deterministic Fix
1. All .canvas cards stacked in a pile at (0, 0) Agent omitted grid spacing or set constant x: 0, y: 0 across nodes. Re-prompt with explicit grid math: x = col * 380, y = row * 240, and run validate_canvas.py to assert zero bounding-box overlaps.
2. Opening a .canvas file shows a blank/error pane Trailing comma after last array item or // comments inside JSON. Run python3 -m json.tool board.canvas > /dev/null to pinpoint the offending line and strip trailing commas/comments.
3. .base date sorting & today() formulas fail Human-written date strings like Nov 12, 2026 or 12/11/26 in YAML. Normalize all YAML date fields to unquoted or quoted strict ISO-8601 YYYY-MM-DD (e.g., due: 2026-11-12).
4. .contains() filter misses matching notes in .base Property mixes scalar strings (tags: "q4") in some notes and YAML lists in others. Standardize multi-value fields as YAML arrays everywhere (tags: [q4]), or wrap mixed properties with list(tags).contains("q4").
5. Canvas file node says "File not found" Agent wrote an OS absolute path (/Users/...) or omitted the .md extension. JSON Canvas "file" paths must be vault-root relative WITH extension (e.g., "Specs/auth-gateway.md", no leading slash).
6. Warning triangle next to property in Sidebar Note value conflicts with global type registered in .obsidian/types.json. Check .obsidian/types.json; convert stray quoted numbers (priority: "1" → 1) or unquoted wikilink arrays ("[[Ada]]").
