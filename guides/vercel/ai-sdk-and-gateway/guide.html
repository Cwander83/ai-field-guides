Reliable Agents with ToolLoopAgent & Output.object()

Stop hand-writing fragile while loops or calling deprecated generateObject(). AI SDK 7 unifies autonomous multi-step tool execution inside ToolLoopAgent and strict JSON validation inside Output.object().

1. ToolLoopAgent + MCP-Aligned Tool Contract

import { ToolLoopAgent, isStepCount, tool } from 'ai';
import { z } from 'zod';

export const supportAgent = new ToolLoopAgent({
  model: 'anthropic/claude-sonnet-4.6',
  instructions: 'Resolve order tickets using verified tools.',
  tools: {
    lookupOrder: tool({
      description: 'Fetch order shipping state by ID.',
      inputSchema: z.object({ orderId: z.string() }),
      outputSchema: z.object({ status: z.string() }),
      execute: async ({ orderId }) => fetchOrder(orderId),
    }),
  },
  stopWhen: isStepCount(6), // Hard safety ceiling
});

// Call agent.generate() or agent.stream() (NEVER generateText!)
const res = await supportAgent.generate({ prompt: 'Check ORD-8841' });

2. Typed Output.object() & ModelMessage

import { generateText, Output, convertToModelMessages, type UIMessage } from 'ai';
import { z } from 'zod';

const TicketSchema = z.object({
  severity: z.enum(['low', 'high', 'critical']),
  category: z.string(),
  actionRequired: z.boolean(),
});

// Convert UIMessage[] from React into ModelMessage[] safely
const modelMessages = await convertToModelMessages(uiMessages);

const { output } = await generateText({
  model: 'openai/gpt-5.4',
  messages: modelMessages,
  output: Output.object({ schema: TicketSchema }),
});
// output is strictly typed: { severity, category, actionRequired }

Streaming React & Multimodal UIs with message.parts

AI SDK 7 replaces flat text strings with structured UIMessage.parts. Stream text deltas, typed tool cards, and custom data chunks cleanly from Fluid Compute routes into React useChat hooks.

1. Server Stream & Multimodal Image Generation

// app/api/chat/route.ts (Node 24 Fluid Compute — no edge runtime!)
import { createUIMessageStreamResponse, createUIMessageStream,
         streamText, convertToModelMessages, generateText } from 'ai';

export async function POST(req: Request) {
  const { messages } = await req.json();
  const result = streamText({
    model: 'anthropic/claude-sonnet-4.6',
    messages: await convertToModelMessages(messages),
  });
  return createUIMessageStreamResponse({ stream: result.toUIMessageStream() });
}

// Custom data parts: use writer.write(), NEVER stream.write()!
const stream = createUIMessageStream({
  execute: async ({ writer }) => { writer.write({ type: 'data-status', data: 'ok' }); },
});

// Multimodal images via Gateway (reads result.files, no DALL-E!)
const img = await generateText({
  model: 'google/gemini-3.1-flash-image-preview',
  prompt: 'Minimalist glass prism studio render',
});
// img.files[0].uint8Array / base64 ready for Vercel Blob

2. React Client: DefaultChatTransport & AI Elements

'use client';
import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';
import { MessageResponse } from '@/components/ai-elements/message';

export function ChatPanel() {
  const { messages, sendMessage, status } = useChat({
    transport: new DefaultChatTransport({ api: '/api/chat' }),
  });

  const busy = status === 'streaming' || status === 'submitted';
  return (
    <>
      {messages.map((m) => m.parts.map((part, i) => {
        if (part.type === 'text')
          return <MessageResponse key={i}>{part.text}</MessageResponse>;
        if (part.type === 'tool-lookupOrder')
          return <OrderCard key={i} state={part.state} data={part.output} />;
        return null;
      }))}
      <button disabled={busy} onClick={() => sendMessage({ text: 'Hi' })}>Send</button>
    </>
  );
}
Safe Streaming Rendering: Never dump raw model strings into dangerouslySetInnerHTML or unguarded Markdown parsers. Render text parts with AI Elements (MessageResponse) so partial markdown tokens, code blocks, and math formulas stream cleanly without XSS or layout flicker.
Composable message.parts Stream: Every response flows down a single Server-Sent Events ribbon as discrete, strongly typed parts—separating prose tokens, tool-<toolName> cards, and generated media files cleanly for React UI components.

09 • Cost Governance, Security & Telemetry Budgets, Auth Hygiene, Prompt Caching & ZDR

Cost Controls, Observability, Auth & Security Hygiene

Production AI apps fail expensively when credentials leak or loops run uncapped. AI Gateway stacks team, project, key, and user budgets with Zero Data Retention routing and OpenTelemetry-ready request logs.

Security Rule: Never Commit Keys or Print OIDC Tokens in Logs
Keep AI_GATEWAY_API_KEY and BYOK provider keys strictly in Vercel Environment Variables or uncommitted .env.local files. Locally pulled VERCEL_OIDC_TOKEN values expire every 12 hours—refresh them with vercel env pull rather than pasting long-lived keys into source.
Stacked Budgets & Credit Controls
  • Four Stacking Scopes: Set limits across team, project (OIDC), api-key, and user. Every active scope must pass or Gateway returns HTTP 402 (quota_for_entity_exceeded).
  • Per-Scope Defaults: Use vercel ai-gateway budgets set api-key --default --amount 50 --refresh-period monthly so new keys inherit caps automatically.
  • Proactive Alerts: Custom budgets email at 50%, 75%, and 100% thresholds; changes propagate within tens of seconds (up to ~5 minutes for hot keys).
! Privacy, Prompt Caching & Safety IDs
  • Zero Data Retention & No Training: Pass zeroDataRetention: true and disallowPromptTraining: true under providerOptions.gateway, or check zdr / no_training fields in /v1/models.
  • Prompt Caching (caching: 'auto'): Injects provider prompt-cache markers on explicit-caching hosts (like Anthropic) for multi-turn prefixes—never use non-existent cacheControl response caching.
  • safetyIdentifier: Send an opaque hashed end-user ID (≤64 chars) so provider abuse filters isolate one user instead of your whole team.

Troubleshooting Clinic & Pre-Flight Checklist

Almost every AI SDK 7 or AI Gateway snag stems from a handful of outdated v4–v6 habits or environment mismatches. Match your symptom below for a ten-second fix, then clear the pre-flight checklist before deploying.

Symptom / Error Root Cause 10-Second Fix
1. export const runtime = 'edge' breaks Node deps Outdated habit added Edge runtime to a route using Node crypto, FS, or Next.js 16.3+ APIs. Delete export const runtime = 'edge' entirely. Node.js 24 LTS on Fluid Compute streams SSE and AI tokens natively.
2. useChat({ api }), handleSubmit, or isLoading Type Error Client code uses removed AI SDK v4 hook signatures instead of v5–v7 transport APIs. Use useChat({ transport: new DefaultChatTransport({ api }) }), sendMessage({ text }), status, and message.parts.
3. generateObject, CoreMessage, or maxSteps Fails Deprecated or removed v4–v6 symbols copied from stale snippets. Switch to generateText + Output.object({ schema }), ModelMessage + convertToModelMessages(), and stopWhen: isStepCount(N).
4. gateway('gpt-5.4') Missing Provider Error Model ID omitted its required vendor prefix (or used hyphenated Claude slugs). Always pass provider/model IDs from /v1/models (e.g., 'openai/gpt-5.4' or 'anthropic/claude-sonnet-4.6').
5. Claude Code Ignores Gateway Key (401) A non-empty ANTHROPIC_API_KEY in your shell overrides ANTHROPIC_AUTH_TOKEN. Explicitly export ANTHROPIC_API_KEY="" alongside ANTHROPIC_BASE_URL="https://ai-gateway.vercel.sh/claude-code" and ANTHROPIC_AUTH_TOKEN.
6. Missing or Expired Local VERCEL_OIDC_TOKEN App runs locally without linking the project or the 12-hour OIDC token expired. Run vercel link && vercel env pull to refresh .env.local, or use AI_GATEWAY_API_KEY for standalone scripts.
7. stream.write is not a function in createUIMessageStream Code calls stream.write() on the returned ReadableStream instead of the writer. Destructure { writer } inside execute: async ({ writer }) => and call writer.write(...).
