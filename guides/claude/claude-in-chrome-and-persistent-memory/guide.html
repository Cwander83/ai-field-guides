  • Site Permissions: Manage approved domains in side-panel Settings → Permissions and Chrome’s chrome://extensions site-access selector.

Anthropic’s Native /memories Tool & Just-in-Time Recall

Instead of dumping sprawling chat histories into every prompt, Anthropic’s native Memory Tool (memory_20250818) gives Claude a structured /memories filesystem to manage long-term facts across sessions using just-in-time retrieval.

The 6 Native /memories File CRUD Commands

Command Exact Behavior & Parameters Best-Practice Rule for Reliable Agents
view Lists directory contents under /memories or reads file lines (supports optional view_range). Always invoke view at task start to orient on existing topic files before writing anything new.
create Writes a brand-new file or overwrites an existing path using path + file_text. Call view first so Claude never clobbers valuable historical notes with an accidental overwrite.
str_replace Replaces one exact unique match via old_str → new_str inside a target file. Prefer str_replace over create for surgical updates to preferences, API endpoints, or dates.
insert Inserts insert_text right before 0-indexed insert_line inside an existing note. Ideal for appending new checklist items or dated changelog bullets without rewriting the whole file.
delete Removes a single stale file or recursively deletes an obsolete folder under /memories. Prune retired experiments promptly and validate path boundaries strictly inside your client handler.
rename Moves or renames old_path → new_path cleanly across your memory tree. Your server handler should throw an error if new_path already exists to prevent silent data loss.

Static Team Contracts vs. Dynamic Learned State

A CLAUDE.md (Human-Authored Rules)
  • Committed in your repo root or ~/.claude/CLAUDE.md and reviewed by teammates via Git PRs.
  • Defines canonical build/test commands, architecture invariants, and security boundaries.
  • Loaded in full every session—keep it declarative and timeless.
B /memories & MEMORY.md (Learned State)
  • Written dynamically by Claude (or stored under ~/.claude/projects/.../memory/) as it learns preferences and fixes.
  • 200-Line / ~25KB Boot Cap: MEMORY.md acts purely as an index; lines past 200 silently truncate!
  • Store rich notes in topic files fetched just in time via view.

09 • Security & Defensive Boundaries Indirect Prompt Injection, Domain Allowlists & /memories Path Jails

Browser Security, Allowlists & Memory Hygiene

Because Claude in Chrome inherits your live cookies and MEMORY.md acts as high-authority startup guidance, browser security and memory sanitization belong in the same threat model.

1 Indirect Prompt Injection & Dual Classifiers
  • Semantic Trap: Malicious webpages, comments, or emails can hide text commands in white-on-white DOM nodes trying to hijack clicks or leak session data.
  • Dual Safety Classifiers: Anthropic screens incoming page text and checks every automated browser action before execution, pausing or blocking risky steps.
  • Patch Discipline: Keep Chrome and the Claude extension auto-updated (hardening origin allowlists & cross-extension boundaries against 2026 ShadowPrompt/ClaudeBleed vectors).
2 Domain Allowlists & Profile Isolation
  • High-Risk Category Blocks: Banking, crypto wallets, medical portals, and explicit domains are blocked by default so agents cannot transfer funds or alter records.
  • Dedicated QA Chrome Profile: Run staging debugging inside a dedicated Chrome work profile—never alongside personal finance, password vaults, or production root consoles.
  • Never Skip Approvals on Open Web: Reserve Skip all approvals strictly for offline/local builds; keep Manually approve or Automatically approve enabled elsewhere.

# Python Client-Side /memories Path Jail (Prevents Directory Traversal Escapes)
from pathlib import Path
MEMORY_ROOT = Path("/srv/agent/workspaces/acme/memories").resolve()

def resolve_memory_path(raw_path: str) -> Path:
    rel = raw_path.lstrip("/")
    if not rel.startswith("memories"):
        raise ValueError("Path must start with /memories")
    candidate = (MEMORY_ROOT.parent / rel).resolve()
    if candidate != MEMORY_ROOT and MEMORY_ROOT not in candidate.parents:
        raise PermissionError(f"Blocked traversal outside jail: {raw_path}")
    return candidate
