CRITICAL PRIVACY RULE: Free Tier vs. Paid Billing Tier
  • Unpaid / Free Tier: Great for learning and public experiments, but prompts and uploads may be reviewed by human annotators and used to train Google models (outside EEA, UK, and Switzerland). Never paste client secrets, private code, or PII on the Free Tier!
  • Paid Billing Tier (Pay-As-You-Go): Linking a Google Cloud Billing account switches your project to strictly private enterprise data handling—zero data is ever used to train Google models—while unlocking frontier models and 1,000+ RPM rate limits.

Mastering the 4 Right-Sidebar Run Settings

1 Thinking Level / Budget

Controls how long Gemini reasons internally before speaking. Use low for instant chat/classification, medium (default) for daily coding & analysis, and high for thorny math, bugs, or strategy.

2 Temperature Slider

Controls randomness. Leave at model default (1.0) for Gemini 3.8/4 reasoning models; lower toward 0.1–0.3 only when demanding strict deterministic extraction on non-thinking tasks.

3 Live Token Counter

Displays exact usage (e.g., 142,810 / 1,048,576 tokens) before you even hit Run—so you always know how much memory and API spend a giant PDF or video consumes.

4 Safety & Output Limits

Adjust harassment/hate/dangerous content filter thresholds for legitimate security or fiction testing, and raise Max output tokens (up to 64K+) so long reports never cut off mid-sentence.

04 • Massive Context Unlocking 1M+ Token Video, PDF, Audio & Codebase Analysis

1M+ Token Superpowers: Drop Everything In at Once

Most AI tools chop long documents into tiny fragments and only "see" a handful of paragraphs at a time. Gemini's native 1,048,576-token window holds an entire hour of video, 1,500 pages of PDFs, or 30,000 lines of code in active memory simultaneously.

VIDEO (~1 HR): Sees visual frames + hears spoken audio together.
PDFS (~1,500 PGS): Reads tables, charts, diagrams & fine print.
AUDIO (~8+ HRS): Distinguishes voices, tone, and exact timestamps.
REPOS (~30K LOC): Maps cross-file bugs & architecture in one shot.

3 Multimodal Power Moves That Save Hours Every Week

1 Visual Video Search

Gemini doesn't just read a transcript—it watches frames! Ask: "List every slide shown on screen with its exact [MM:SS] timestamp and transcribe any whiteboard diagrams." YouTube URLs can be pasted directly too.

2 Cross-Document Diffs

Drop both last year's 200-page vendor contract PDF and this year's renewal PDF into one prompt. Ask: "Build a table of every clause, fee, or SLA threshold that changed, citing exact page numbers."

3 Media Resolution Dial

Analyzing a 2-hour video? Lower Media Resolution in Run Settings to pack 2–3x more footage into 1M tokens. Reading tiny dense architectural blueprints? Set Media Resolution to High!

05 • Steering & Tools Bulletproof System Instructions, Built-In Tools & Compare Mode

System Instructions, Live Grounding & Python Sandbox

Stop repeating "be concise, don't make things up, format as a table" in every message. Moving your rules into System Instructions and flipping on AI Studio's built-in tools transforms Gemini from a chatbot into a verifiable analyst.

The 5-Part System Instruction Blueprint (Color-Coded Template)

[ROLE] You are a Principal Financial & Operations Analyst reviewing quarterly executive packets. [CONTEXT] My company sells B2B SaaS; prioritize net retention, CAC payback, and margin shifts. [TASK RULES] Ground every number in uploaded files or URL Context; cite [Doc Name, Page #] inline. [OUTPUT FORMAT] Start with a 3-bullet TL;DR, followed by a Markdown variance table and open risks. [GUARDRAILS] Never guess missing figures—write "Not disclosed in source" if a metric is absent.

Flipping On Gemini's Four Super-Tools (Right Sidebar)

1 Grounding with Google Search

Connects Gemini to live Google Search results so it can verify today's pricing, recent news, library releases, or competitor announcements—complete with clickable source citation chips below every answer.

2 URL Context (Live Page Reader)

Paste up to 20 public URLs directly in your prompt (docs pages, articles, pricing pages) with URL context enabled. Gemini fetches and reads the full pages on the fly—no manual copy-pasting!

3 Code Execution (Python Sandbox)

Never let an LLM do mental math on a 10,000-row CSV! With Code execution on, Gemini writes and runs real Python (pandas, matplotlib) inside a secure Google sandbox to calculate exact numbers and plot charts.

4 Function Calling (Custom Tools)

Prototyping an agent? Paste tool schemas (like check_inventory(sku) or create_ticket()) into the Function Calling modal to test whether Gemini triggers the right parameters before writing backend glue.

Power Habit: Use Compare Mode (⇄) Before Committing to a Model
Click the Compare icon in the top bar to open two synchronized panels. Put gemini-4-argon on the left and gemini-3.8-flash on the right—or test two different System Instructions on the same model. One prompt fires both panels simultaneously so you can compare speed, token cost, and quality side by side!
Bonus Trick: Edit Any Past Turn in Place
Made a typo three turns ago, or wish Gemini had phrased an earlier answer differently? Hover over any user or model message in AI Studio, click the Pencil icon to edit it (or branch from that point), and click Rerun!

09 • Developer Handoff API Keys, Official google-genai SDKs & Graduating to Google Antigravity

API Keys, Get Code & Scaling in Antigravity

When a prompt or prototype inside AI Studio works so well you want to automate it in Python/TypeScript or turn it into a production company product, AI Studio hands you clean starter code in seconds.

Step 1: Mint & Protect Your GEMINI_API_KEY

  • Click Get API key in the bottom-left rail → create a key linked to a Paid Tier project for private zero-training production traffic.
  • Store it in your shell or .env file as export GEMINI_API_KEY="your_key_here"—the official SDKs detect that exact variable name automatically so you never hardcode keys inside source files or public GitHub repos!

Step 2: Use Only Current Official SDKs (google-genai & @google/genai)

Python • pip install -U google-genai
from google import genai

client = genai.Client()  # Uses GEMINI_API_KEY

res = client.interactions.create(
    model="gemini-3.8-flash",
    system_instruction="Reply in 3 crisp bullets.",
    input="Why 1M context beats RAG chunking.",
    tools=[{"type": "google_search"}],
    generation_config={"thinking_level": "medium"},
)
print(res.output_text)
TypeScript • npm install @google/genai
import { GoogleGenAI } from "@google/genai";

const ai = new GoogleGenAI({}); // GEMINI_API_KEY

const res = await ai.interactions.create({
  model: "gemini-3.8-flash",
  system_instruction: "Reply in 3 crisp bullets.",
  input: "Why 1M context beats RAG chunking.",
  tools: [{ type: "google_search" }],
  generation_config: { thinking_level: "medium" },
});
console.log(res.output_text);
SDK Trap to Avoid: Never Install Legacy google-generativeai!
Older blog posts online show import google.generativeai or @google/generative-ai and gemini-1.5 / gemini-2.0 models—those are deprecated. Always use google-genai (Python) and @google/genai (JS/TS) with the modern client.interactions.create() API!

1 Vibe-Code in AI Studio

Validate the core Gemini prompts, UI flow, and live preview in 10 minutes inside AI Studio's Build tab.

2 Sync to GitHub

Open Build Settings → GitHub to push your app to a private repository with two-way sync (or export ZIP).

3 Scale in Antigravity

Clone the repo in Google Antigravity so autonomous coding agents add auth, Postgres, Playwright tests & CI/CD!
