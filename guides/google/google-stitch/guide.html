02 • Setup & Modes Mobile vs. Web Targets & Choosing Your Generation Engine

First Launch: Targets, Modes & Monthly Allowances

Before typing your first prompt at stitch.withgoogle.com, two quick toggles at the bottom of the composer shape everything Stitch builds: your Device Target (Mobile vs. Web) and your Model Mode (Standard vs. Experimental).

3 Steps to Your First Shippable Screen (Under 60 Seconds)

1 Launch Stitch Canvas

Sign in at stitch.withgoogle.com with your Google account. Click New Project to open a fresh infinite canvas with Agent Manager ready.

2 Select Mobile or Web

Pick Mobile for touch-first iOS/Android screens (390px–430px) or Web for responsive desktop dashboards, SaaS apps, and landing pages.

3 Pick Mode & Generate

Choose Standard for rapid multi-screen flows + native Figma paste, or Experimental for sketch/image uploads and high-craft aesthetics.

Standard Mode vs. Experimental (Pro) Mode: When to Use Which

Capability Standard Mode (Gemini Flash Engine) Experimental / Pro Mode (Gemini Pro Engine)
Primary Strength Blazing-fast multi-screen ideation, structured design systems, and rapid conversational tweaks. Deep visual reasoning, bespoke editorial/3D aesthetics, and complex spatial layout interpretation.
Image & Sketch Uploads Text prompts, URL-to-theme context, and conversational screen edits. Full Multimodal Seed Support: Upload napkin sketches, whiteboard photos, wireframes & screenshots!
Paste to Figma Native 1-Click Copy to Figma (pastes clean editable Auto-Layout frames directly). Exports clean HTML/Tailwind code (importable to Figma via html.to.design or Stitch plugin bridge).
Frontend Code Export Clean semantic HTML5 + Tailwind CSS + live preview + Stitch MCP access. Rich custom CSS variables, nuanced gradients, HTML5/Tailwind markup + Stitch MCP access.
Monthly Allowance Generous high-volume pool (~350 generations/month standard baseline; expanded in AI Ultra workflows). Dedicated high-reasoning monthly pool (~50–100 Pro generations/month; save for hero look-dev & sketches).

Choosing Mobile vs. Web Target Before You Prompt

When to Pick "Mobile" Target
Automatically enforces thumb-friendly bottom navigation bars, stacked card rhythms, safe-area top headers, swipeable pill carousels, and slide-up action sheets ideal for React Native, Flutter, SwiftUI, or mobile-web PWAs.
When to Pick "Web / Desktop" Target
Unlocks collapsible left navigation rails, multi-column Bento analytics grids, filterable data tables, split-pane inspector drawers, and wide hero sections tailored for Next.js, React, and SaaS web platforms.

04 • Multimodal Inputs Turning Napkin Sketches, Wireframes & Screenshots into UI

From Napkin Sketch or Screenshot to Production UI

Sometimes drawing three boxes on dotted paper is ten times faster than explaining a spatial layout in words. Switch Stitch to Experimental Mode, click the attachment icon, and let Gemini Vision translate rough ink into polished UI and clean DOM structure.

1. PAPER SKETCH: Simple boxes, avatar circles & hierarchy lines.
2. GEMINI PARSING: Infers Auto-Layout stacks, cards & chart zones.
3. STITCH OUTPUT: High-craft themed UI + semantic HTML/Tailwind!

3 Multimodal Upload Workflows Every Designer Should Master

1 Paper & Whiteboard

Use dark felt-tip pen on plain or dotted paper. Draw clear bounding boxes, standard [X] image placeholders, and short section labels, then snap a well-lit overhead photo without harsh shadows.

2 Screenshot Remixing

Upload a screenshot of an existing app (or your legacy v1 product) and prompt: "Keep this information architecture, but redesign for a luxury veterinary clinic in warm sage and cream."

3 URL & Moodboards

Point Stitch at your live marketing URL—or upload a brand style tile—to automatically extract colors, font mood, and button geometry into a reusable DESIGN.md system!

Image-Input Best Practices (Avoiding Misread Layouts)

Input Type Do This Avoid This
Hand-Drawn Sketch Crop tightly to a single screen frame (or clearly numbered frames) with bold marker lines. Cursive margin notes, crossed-out scribbles, or angled perspective photos across two laptop monitors.
Existing App Screenshot Tell Stitch explicitly what to keep (layout grid) vs. what to replace (industry, brand palette, data). Uploading a screenshot with zero text prompt—Stitch won't know whether to modernize or clone it.
Golden Formula: Visual Seed = "Where Things Go" • Text Prompt = "How It Feels"
Never waste time shading buttons on paper! Let your 30-second sketch control spatial hierarchy, and add one crisp sentence: "Turn this wireframe into a dark-mode podcast studio dashboard with emerald waveform cards and crisp tabular metrics."

06 • Flows & Iteration Designing Cohesive Multi-Screen User Flows & Surgical Edits

Building Cohesive Multi-Screen Flows & Surgical Edits

Real software isn't one hero screen—it is an end-to-end journey. Stitch's infinite canvas and Agent Manager let you map 4 to 8 connected screens that share identical navigation chrome, spacing rhythm, and theme tokens.

The "Anchor First, Expand Second" Workflow (Best Consistency)

  1. Nail One Anchor Screen First: Generate your core Home Dashboard or Product Page first, explore 2–3 layout variants, and dial in your exact Global Theme palette, font, and radius.
  2. Expand the Flow From Your Anchor: Select that winning screen on the canvas and prompt: "Using this exact design system and navigation bar, generate 3 connected screens: (1) Onboarding Sign-In, (2) Analytics Drill-Down, and (3) User Settings."
  3. Link Interactive Hotspots: Toggle Stitch's Prototype / Live Mode to connect buttons across screens and click through the live user journey in your browser before writing a line of backend code.

Surgical Conversational Edits (Changing 10% Without Breaking 90%)

✓ Scoped Component Prompts

Click the specific screen or section first, then write a surgical delta: "Keep the header and KPI row untouched; replace only the bottom activity feed with a 5-row sortable invoice table with Paid/Pending status pills."

⚠ Branching Variants Safely

Want to test a bold new layout without risking your current favorite? Click Duplicate / Generate Variants on the canvas so Agent Manager explores 3 parallel options side by side while preserving your original frame.

07 • Figma & Code Export Seamless Handoff: Copy to Figma & Production HTML/Tailwind

Design-to-Dev Handoff: Paste to Figma & Clean Code

Stitch eliminates the dead-end "static mockup trap." Whether your next stop is a collaborative design critique in Figma or a live repository in Google Antigravity, your work travels with full structure intact.

A One-Click "Paste to Figma" Workflow
  1. Select any screen (or multi-screen group) generated in Standard Mode.
  2. Click Copy to Figma in the top action bar.
  3. Open any Figma design file and press Cmd + V (Mac) or Ctrl + V (Windows).
  4. Inspect your layers: Stitch creates real nested Figma Auto-Layout frames (horizontal/vertical padding & gap rules), editable text nodes, crisp SVG icons, and clean fill tokens!

Tip for Experimental Mode screens: Export the screen's HTML or live preview link and import via Figma's html.to.design plugin to preserve editable layers.

B Clean HTML & Tailwind CSS Export
  1. Click any screen and open the </> Code drawer (or toggle Live Preview to test responsive resizing).
  2. Copy or download the single-file HTML5 + Tailwind CSS bundle.
  3. What's inside: Semantic tags (<nav>, <main>, <section>), clean Flexbox/CSS Grid classes, Google Fonts links, and zero absolute-positioned spaghetti!
  4. Download DESIGN.md alongside your code to document every color, font, and spacing token for AI coding agents.

Choosing the Right Stitch Export Path for Your Team

Export Format What Gets Transferred Best When You Need To...
Copy to Figma Editable Auto-Layout frames, vector icons, text layers & fills. Co-edit with product designers, attach to an existing enterprise Figma component library, or run stakeholder redlines.
HTML + Tailwind CSS Responsive semantic DOM markup + Tailwind utility classes. Drop directly into a prototype server, convert into React/Vue/Svelte components, or deploy an instant landing page.
DESIGN.md File Structured Markdown design-system contract (tokens & UX rules). Commit into your Git repo root so Google Antigravity, Jules, or Claude/Cursor enforce your exact aesthetic on every PR.
Stitch MCP Server Live API bridge exposing all Stitch projects, screens & code. Let Google Antigravity pull screens directly into Next.js, Flutter, or Swift projects with zero manual copy-paste (Page 11!).
2-Minute Figma Hygiene Habit After Pasting
Right after pressing Cmd + V in Figma, select the pasted frame, verify your Google Font is installed locally, and click Create Component on repeated navbars and cards—you just turned a 20-second AI generation into a reusable design system!

09 • UX Craft & A11y Visual Hierarchy, Contrast, Touch Targets & Real-World Edge States

Elevating AI Mockups into Shippable, Accessible UX

Left unguided, any AI UI tool will happily pack twelve charts onto one phone screen or place pale mint text on a white button. Apply these four senior UX guardrails inside Stitch so your designs pass real engineering and accessibility reviews.

1 Enforce the "One Primary Job" Rule

Every screen needs one unmistakable primary action and 3–4 content groups max. Include "generous 24px section spacing, progressive disclosure, and a single high-contrast primary CTA" in prompts to prevent cramped dashboard soup.

2 WCAG AA Contrast & Surface Steps

When using bright accents like mint (#34D399) or amber (#FBBF24), instruct Stitch: "Use dark obsidian text (#042F2E) on bright accent buttons for 7:1 WCAG contrast, and step dark cards cleanly from #0B1120 bg to #1E293B surface."

3 Ergonomic Touch & Click Targets

For Mobile targets, ask for "minimum 44x44px tap targets, 8px minimum gap between icon buttons, and primary actions anchored in the lower thumb zone"—critical before exporting to SwiftUI or Flutter.

4 Always Generate the "Unhappy Paths"

Developers stall when designs only show sunny-day data! Ask Stitch to generate matching frames for: Zero-Data Empty State, Skeleton Shimmer Loading, Inline Form Error State, and Confirmation Toast.

Quick Audit: Turning "AI Demo Smells" into Production Polish

Common "AI Mockup Smell" 10-Second Conversational Fix Inside Stitch

Troubleshooting Clinic & Pre-Flight Cheat Sheet

Top 7 Google Stitch Issues & 10-Second Fixes

Symptom / Problem Root Cause & 10-Second Fix
Copy to Figma button is grayed out or missing Screen was generated in Experimental Mode. Re-generate or branch in Standard Mode for native 1-click Figma paste, or import Experimental HTML via Figma's html.to.design plugin.
Sketch/wireframe upload icon isn't clickable Workspace is currently set to Standard Mode text-only flow. Toggle the mode selector to Experimental (Pro) Mode to unlock multimodal sketch and screenshot attachments.
Editing one widget accidentally redesigned the whole screen Prompt was sent globally without scoping. Click the specific screen/section first and prefix with: "Keep header, nav, and palette identical; update ONLY the..."
Multi-screen flow drifts in button shape or colors Screens were prompted in separate unlinked sessions. Set your Global Theme Bar (accent, font, radius) on Screen 1 first, then select Screen 1 and ask Stitch to expand companion screens from it.
Generated screen feels overcrowded & claustrophobic Prompt listed too many widgets for one viewport. Ask Stitch: "Increase whitespace and card padding to 24px; move secondary settings into a slide-over drawer."
Hand-drawn sketch produced weird floating boxes Low-contrast pencil or angled shadow in photo. Retake flat overhead in bright light with dark marker boxes, and add a 1-sentence prompt naming each boxed zone.
Pasted Figma text wraps slightly differently Missing local Google Font in Figma Desktop. Install the matching Google Font (e.g., Plus Jakarta Sans or Inter) or select all and apply your team's Figma text style.
