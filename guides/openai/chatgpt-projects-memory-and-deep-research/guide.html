2 File Caps & Memory Prerequisite Steps
  • Per-File Limits: Max 512 MB per upload (~2M tokens for docs/text, 50 MB for CSVs/spreadsheets, 20 MB for images), queued in batches of up to 10 files.

  • Creation-Time Lock: Pick Project-only memory in Project settings when creating a confidential workspace so personal habits never leak in.
  • Connected Sources: Authorize Google Drive, SharePoint, GitHub, or Slack under Settings → Connected apps before launching Deep Research.

04 • Projects & Memory Isolation Custom Instructions, File Libraries & Project-Only Sandboxes

Mastering Projects & Memory Isolation Walls

Most ChatGPT memory mistakes happen silently: you switch from planning a weekend trip to reviewing an acquisition NDA, and personal preferences spill into the draft. Configuring Projects with intentional memory walls stops cross-contamination before it starts.

Strict Memory Partitioning: Each Project-Only sanctuary lets sibling threads and uploaded files cross-reference freely inside its walls while blocking personal global memories and neighboring projects from crossing the emerald barrier.
1 Default vs. Project-Only Memory

In Default mode, project threads pull both your uploaded files and your account-wide saved memories. In Project-Only mode, ChatGPT builds a hard boundary: chats inside can reference sibling project threads and files, yet stay completely blind to global memory and outside chats.

2 Overriding Global Custom Instructions

Keep global settings (Settings → Personalization) focused on universal formatting and brevity. Put domain voice, citation requirements, and client constraints inside Project Instructions—they override global instructions automatically while you work in that project.

High-Signal Project Instructions Template (Paste Into Project Settings)

Role: You are our Senior Compliance Research Analyst for the Acme Q4 EU Audit Project.
Sources First: Always check uploaded files tagged [CANONICAL] before searching the web.
Citation Rule: Quote exact file names and page numbers for internal specs, plus clickable URLs for laws.
Isolation Rule: Do not infer personal preferences outside this project; flag missing data as [OPEN GAP].
Output Style: Lead with a 3-bullet executive verdict, followed by a markdown table of action owners.
Pro Tip: Lock Project-Only Memory Before Uploading Sensitive Files
Set your container to Project-Only the moment you create a new client or legal project (remember that account memory must be enabled globally for the isolation engine to run). If a project is shared with teammates on Business or Enterprise, ChatGPT locks it to Project-Only automatically.

Color-Coded Project & Deep Research Anatomy

Vague research prompts waste Deep Research monthly allowances on generic blog summaries. Combining these six color-coded clauses keeps your Project instructions airtight and steers Deep Research toward primary sources on the very first pass.

[1. Role & Objective] [2. Internal File Priority] [3. Memory Boundary] [4. Source & Domain Scope] [5. Verification Guard] [6. Deliverable & Handoff]

Formula 1: Deep Research Prompt Inside a Scoped Project

“Act as a B2B payments pricing analyst evaluating our 2026 EU merchant expansion. First extract our baseline unit economics from uploaded Project file 03_[DATA]_EU_Cohort.csv and 01_[CANONICAL]_Fee_Schedule.pdf. Stay strictly inside this Project-Only context without pulling personal assumptions from unrelated chats. Search only primary regulatory filings (eur-lex.europa.eu), card-network bulletins (Visa/Mastercard), and public Adyen/Stripe 2026 annual reports; skip SEO listicles. Present your multi-step Research Plan for my approval before browsing, and mark any unverified fee estimate as [NEEDS VERIFICATION]. Deliver a cited comparison table ready to open in Canvas and export as Markdown.”

Formula 2: Mid-Run Steering Prompt (Redirecting Without Restarting)

Mid-Run Steer Command (typed while Deep Research progress log is active):
"Pause US interchange comparisons—we already covered those in our Q2 Project thread. Redirect the remaining search steps exclusively to PSD3 instant-payment caps in Germany and France from 2025-2026 official central bank publications, then contrast them against rows 12-40 of our uploaded EU_Cohort CSV."

Clause-by-Clause Breakdown: Eliminating Drift & Wasted Quotas

Clause Tag What It Controls Failure Mode When Omitted
Role & Objective Locks analytical lens, industry vocabulary, and decision criteria. Report reads like a broad encyclopedia article instead of an actionable brief.
Internal File Priority Forces Deep Research to benchmark web findings against your Project PDFs/CSVs. Agent relies only on public internet data and ignores your proprietary numbers.
Memory Boundary Reinforces Project-Only isolation or specifies which sibling thread holds context. Old assumptions or personal tone preferences sneak into client-facing outputs.

Verification Guard Requires pre-run plan approval and forces explicit uncertainty flags on gaps. Agent extrapolates missing pricing figures smoothly without warning you.
Deliverable & Handoff Targets exact export shape (Canvas draft, Markdown dossier, or Space Page table). Requires manual reformatting before teammates can edit or ship the findings.

06 • Autonomous Deep Research Plan Editing, Live Steering, Citations & Multi-Format Export

Autonomous Deep Research: Steer, Verify & Ship

Powered by OpenAI’s GPT-5 reasoning stack (with faster lightweight runs and exhaustive full passes), Deep Research spends 5 to 30 minutes autonomously browsing the web, reading your uploaded Project files, and checking connected workspace apps before returning a cited dossier.

Guided Autonomous Synthesis: Rather than firing blindly, Deep Research fans out across whitelisted web pages, uploaded PDFs, and connected drives, then weaves clickable primary citations into an interactive viewer ready for Canvas or Space handoff.
1 Edit Plan Before Launching

After you submit a query, Deep Research drafts a multi-step investigation outline. Click Edit Plan to narrow countries, specify date cutoffs (2025–2026 only), restrict domains, or anchor the run to specific Project files and Google Drive folders.

2 Steer & Interrupt Live

Watch the live reasoning and browsing feed as the agent works. If you spot it chasing an outdated forum or wrong subsidiary, send a steering note mid-run to redirect its search tree without throwing away the sources it already verified.

3 Audit Citations in the Viewer

Finished reports open in a full-screen Interactive Viewer with a Dynamic Table of Contents, activity log, and inline source-citation drawer. Click through primary PDFs and URLs directly to confirm statistics before sharing externally.

4 Export or Open in Canvas

Export clean dossiers as Markdown, Word (.docx), or PDF, or click Open in Canvas to trim executive summaries, build React visualizers, and promote finalized briefs into a shared team Space Page. 

Citation Audit Follow-Up (run inside the completed Deep Research thread before exporting):
"Review every quantitative figure in Sections 2 and 3. List any statistic that came from a secondary blog rather than a primary 2025-2026 filing, and propose exact replacement searches to verify those rows."

Privacy, Team Sharing & Memory Governance

Persistent memory and connected-app Deep Research touch your organization’s most sensitive documents. Knowing exactly when OpenAI trains on data, how shared Projects wall off personal memories, and when to reach for Temporary Chat keeps your workspace audit-ready.

1 Consumer Memory Hygiene (Plus / Pro)
  • Training Opt-Out: Turn off Settings → Data Controls → Improve the model for everyone before uploading proprietary drafts on individual plans.
  • Prune Saved Memories: Audit Settings → Personalization → Memory → Manage monthly to delete stale client names or one-off preferences.
  • Temporary Chat Escape Hatch: Open a Temporary Chat whenever testing sensitive HR, legal, or credential-adjacent drafts you never want remembered.
2 Business, Enterprise & Regulated Controls
  • Zero Training by Default: OpenAI never trains foundation models on Business, Enterprise, or Edu Project files, Deep Research runs, or memory entries.
  • Shared Project Memory Wall: Sharing any Project enforces Project-Only isolation automatically—collaborators never see your global account memories.
  • Regulated Workspaces: In Enterprise Regulated or Healthcare workspaces, improved memory defaults to Off until workspace admins explicitly enable scoped roles.
