End-to-End Request & State Lifecycle at the Edge

When a user or webhook targets an agent by name (e.g., tenant-42-analyst), Cloudflare routes the request to that exact Durable Object anywhere on the network. The agent reads local SQLite in microseconds, calls models via AI Gateway, and spins up an isolated Container Sandbox only when untrusted code execution is required:

1 Zero-Cold-DB State

SQLite runs inside the same process boundary as your Durable Object. Queries execute synchronously with zero network round-trips and survive evictions automatically.

2 Hibernation = $0 Idle

Durable Objects hibernate open WebSockets and Workflows sleep on step.waitForEvent() without charging wall-clock compute while waiting for humans or webhooks.

3 Isolates First, Containers Next

Run lightweight JS/TS agent logic in V8 isolates (or Dynamic Workers) in milliseconds, and attach a Linux container via ctx.container only when POSIX tools are needed.

Embedded SQLite, Hibernatable WebSockets & Durable Scheduling

Subclassing Agent<Env, State> from the agents package turns a Cloudflare Durable Object into a persistent, real-time agent runtime with four built-in durability primitives—requiring zero external databases or message brokers.

Anatomy of a Durable Agent: Embedded SQLite plates (this.sql & this.setState) sit directly inside the isolate, surrounded by hibernatable WebSocket channels and a SQLite-backed cron/alarm scheduler.
1 Dual Persistence: setState() + this.sql

Call this.setState(next) to atomically write JSON state to cf_agents_state and broadcast a cf_agent_state sync frame to all connected React/JS clients. Use tagged-template this.sql`...` for relational audit logs, message histories, and tool ledgers.

2 Hibernatable WebSockets & useAgent

WebSockets stay open at the Cloudflare edge even when the DO hibernates to zero memory. Store per-socket metadata with connection.setState(); the official React useAgent() hook auto-reconnects and syncs state bi-directionally.

3 Durable Jobs: this.schedule()

Schedule delayed seconds (60), exact Date timestamps, or cron strings ("0 * * * *"). The SDK stores jobs in SQLite and multiplexes them onto the DO’s single alarm so independent schedules never overwrite each other.

4 Long Tasks & Human-in-the-Loop

Wrap critical active work in keepAliveWhile() to prevent mid-call eviction, or use runFiber() + stash() to checkpoint long multi-turn runs and pause for human approval at $0 idle cost.

import { Agent, routeAgentRequest } from "agents";

interface OpsState { pendingApproval: string | null; runs: number; }

export class OpsAgent extends Agent<Env, OpsState> {
  initialState: OpsState = { pendingApproval: null, runs: 0 };

  async onStart() {
    this.sql`CREATE TABLE IF NOT EXISTS audit (id TEXT PRIMARY KEY, action TEXT, ts INTEGER)`;
    await this.schedule("0 * * * *", "hourlyDigest", { channel: "ops" }); // SQLite-backed cron
  }

  async requestDeploy(releaseId: string) {
    this.sql`INSERT INTO audit (id, action, ts) VALUES (${crypto.randomUUID()}, ${releaseId}, ${Date.now()})`;
    this.setState({ ...this.state, pendingApproval: releaseId }); // Persists & pushes over WS
  }

  async hourlyDigest(payload: { channel: string }) { /* wakes DO via alarm, runs, then hibernates */ }
}

export default { fetch: (req: Request, env: Env) => routeAgentRequest(req, env) };

Cloudflare Containers & Ephemeral Code Sandboxes

When an AI agent writes Python data scripts, runs npm test, or edits a Git repository, you must never execute that untrusted code inside your application’s memory space. Cloudflare’s rebuilt Containers and Sandbox SDK 1.0 (Sep 2026) let each Durable Object spawn, exec, snapshot, and sleep an isolated Linux workspace directly at the edge.

1 Native this.ctx.container Architecture
  • 6x Faster Agent Starts: Rebuilt container control plane boots on-demand Linux sandboxes directly from your Durable Object.
  • Runtime Selection: Choose Docker image, instance size, and idle sleep policy dynamically in code per tenant or task.
  • Beta Filesystem Snapshots: Snapshot disk state before sleeping so a coding agent resumes its exact repo checkout and build cache.
2 Isolates First, Containers On Demand
  • Dynamic Workers: For AI-generated JS/TS transforms and “Code Mode” tool calls, spawn ephemeral V8 isolates ~100x faster than Linux containers.
  • Sandbox SDK 1.0: Utility helpers (command exec, file read/write, streaming stdout, preview ports) that work alongside ctx.container.
  • @cloudflare/computer: Higher-level workspace combining Dynamic Workers + Containers with a synchronized filesystem.

Safe Untrusted Execution Pattern Inside a Durable Object

import { Agent } from "agents";
import { execInSandbox, writeFiles } from "@cloudflare/sandbox";

export class CodeRunnerAgent extends Agent<Env> {
  async runUserScript(pyCode: string) {
    // 1. Start or wake the DO's dedicated Linux container with runtime image & tight idle sleep
    await this.ctx.container.start({
      image: "registry.cloudflare.com/your-acct/py-sandbox:3.12",
      instanceType: "lite",
      sleepAfter: "5m",
      enableInternet: false, // Block lateral/egress exfiltration by default
    });
    // 2. Write untrusted code & execute with hard timeout; credentials stay in DO, never on disk
    await writeFiles(this.ctx.container, [{ path: "/workspace/task.py", content: pyCode }]);
    const res = await execInSandbox(this.ctx.container, "python3 /workspace/task.py", { timeoutMs: 15_000 });
    return { exitCode: res.exitCode, stdout: res.stdout.slice(0, 8000), stderr: res.stderr.slice(0, 2000) };
  }
}

5 Non-Negotiable Sandbox Security & Cost Rules

Control Implementation Rule Threat / Failure Prevented
No Secrets on Disk Never write API keys or OAuth tokens into container env files or filesystem snapshots; proxy outbound API calls through the parent DO. Prompt-injected code reading /proc/self/environ or leaking snapshot credentials.
Default-Deny Egress Set enableInternet: false unless required, or route egress through a Worker allowlist proxy. Data exfiltration, SSRF against internal endpoints, and crypto-mining abuse.
Hard Exec Timeouts Enforce 10–30s command timeouts and truncate stdout/stderr before feeding output back to the LLM context. Infinite loops burning vCPU and token-bombing your LLM bill.
Per-Tenant Instance Caps Track active container leases in DO SQLite / KV and enforce a max concurrent sandbox count per organization. Runaway parallel tool calls causing unexpected Workers Paid container spend.
Aggressive Idle Sleep Set sleepAfter to 2m–5m and snapshot only clean workspace directories (excluding /tmp). Paying for idle Linux containers between sporadic user chat turns.

Recipe A: Durable Human-in-the-Loop Workflow (src/approval-workflow.ts)

import { WorkflowEntrypoint, WorkflowEvent, WorkflowStep } from "cloudflare:workers";

export class DeployApprovalWorkflow extends WorkflowEntrypoint<Env, { releaseId: string; agentId: string }> {
  async run(event: WorkflowEvent<{ releaseId: string; agentId: string }>, step: WorkflowStep) {
    const summary = await step.do("risk-brief", () =>
      this.env.AI.run("@cf/meta/llama-3.3-70b-instruct-fp8-fast", { prompt: `Risks for ${event.payload.releaseId}` })
    );
    // Sleeps at $0 compute cost until operator clicks Approve in the Agent UI
    const decision = await step.waitForEvent<{ approved: boolean }>("human-approval", {
      type: "deploy-decision", timeout: "24 hours",
    });
    if (decision.payload.approved) {
      await step.do("notify-agent", async () => {
        const stub = this.env.OPS_AGENT.get(this.env.OPS_AGENT.idFromName(event.payload.agentId));
        await stub.fetch("https://agent/approved", { method: "POST", body: JSON.stringify(summary) });
      });
    }
  }
}

End-to-End Edge Agent Synergy Pipeline

Production AI applications rarely stop at a single chat box. Here is how a React/Next.js frontend, Cloudflare Agent Durable Object, AI Gateway, R2/Vectorize RAG layer, and Container Sandbox interlock into one globally distributed, low-latency pipeline.

5-Stage Operational Flow (From Click to Verified Output)

1 Zero-Hop Client Sync

Next.js authenticates the user via OAuth 2.1 / Access and opens a persistent WebSocket to the tenant’s Agent DO via useAgent(). Every state mutation pushes instantaneously to all open browser tabs.

2 Grounded Edge Retrieval

Before calling a frontier model, the Agent queries recent turn context from local SQLite and fetches top-K domain passages from Vectorize or AI Search (backed by R2 buckets) in a single region.

3 Guarded Multi-Model Inference

The prompt passes through AI Gateway for DLP redaction, exact-match cache lookup, and dynamic routing—failing over seamlessly if the primary provider rate-limits.

4 Sandboxed Execution & Artifacts

When the LLM emits a code or repo tool call, the DO wakes this.ctx.container, runs the script with a hard timeout, uploads generated charts/CSVs to R2, and returns a signed URL to the client.

Stage 5: Durable Handoff & Hibernation
Once the turn completes, the Agent checkpoints its ledger in SQLite, schedules any follow-up check via this.schedule(), lets the Container Sandbox sleep after 3 minutes, and hibernates its own WebSocket—dropping steady-state cost to near zero until the next event arrives.

DO deploy fails on SQLite
new_sqlite_classes required		 Class bound in durable_objects.bindings without a matching SQLite migration entry. Add "migrations": [{ "tag": "v1", "new_sqlite_classes": ["MyAgent"] }] and match exported class name exactly.
McpServer not assignable
TypeScript build error		 Two different versions of @modelcontextprotocol/sdk installed in node_modules. Run npm ls @modelcontextprotocol/sdk and pin the exact version required by your agents release.
Could not resolve "ai"
Bundler fails on MCP deploy		 agents dynamically imports Vercel’s ai package on client paths even if unused. Install ai in dependencies (npm i ai) and ensure compatibility_flags: ["nodejs_compat"] is set.
Env untyped / red squiggles Added a new DO, AI, KV, or Workflow binding in wrangler.jsonc without regenerating types. Run npx wrangler types after every config edit (and in CI before tsc --noEmit).
State lost after WS idle Stored session variables on in-memory this.foo fields instead of SQLite/WebSocket state. Persist shared state with this.setState() / this.sql and per-socket state via connection.setState().
OAuth MCP 401 Invalid Token MCP_RESOURCE in wrangler.jsonc still points to localhost instead of prod URL. Set MCP_RESOURCE to the exact public https://.../mcp URL clients connect to; redeploy.
No snapshots / slow container Still extending legacy Container or Sandbox wrapper classes (frozen Dec 31, 2026). Migrate to native this.ctx.container with durable_object scheduling + Sandbox SDK 1.0 helpers.

6-Point Production Launch Pre-Flight Checklist

✓
1. Tenant-Bound Routing: Edge Worker validates OAuth 2.1 / Access JWT and derives the Durable Object ID from verified claims—never raw URL params.
✓
2. SQLite Migrations & Types: Every Agent and McpAgent is listed in new_sqlite_classes, nodejs_compat is enabled, and wrangler types passes cleanly.
✓
3. AI Gateway Guardrails: All model calls route via dynamic/<route> with a fallback provider, cf-aig-cache-ttl, rate limits, DLP, and Llama Guardrails enabled.
✓
4. Hardened Sandboxes: Containers use native ctx.container with enableInternet: false, 15s exec timeouts, 3–5m idle sleep, and zero secrets on snapshot disks.
✓
5. Hibernation & Loop Caps: Verified state survives DO eviction, Workflows sleep on waitForEvent(), and agent tool loops enforce a hard maxSteps ceiling.
✓
6. End-to-End Observability: Workers Logs active, cf-aig-metadata tagged with tenant & workflow IDs, and npx wrangler tail smoke-tested on staging.
