Docling: PDF Layout, TableFormer & VLM Conversion

Developed by IBM Research, Docling replaces brittle text dumpers with deep layout analysis, converting PDFs, Word files, slide decks, and scanned archives into a structured DoclingDocument tree.

1Unified DoclingDocument

Represents titles, nested headings, reading order, captions, code blocks, and formulas in one schema exporting cleanly to Markdown, HTML, JSON, or DocTags.

2TableFormer Cell Grid

Predicts bounding boxes, row spans, and multi-tier headers. Choose FAST for high volume or ACCURATE for dense financial tables.

3Modular OCR & VLM

Swap between RapidOCR, EasyOCR, Tesseract, and macOS Vision, or run Granite-Docling (258M) end-to-end via VlmPipeline.

Docling Formula: Pipeline Options (PdfPipelineOptions) + Selective OCR (RapidOcrOptions) + Table Mode (TableFormerMode.ACCURATE) + Converter (DocumentConverter) 
from docling.datamodel.base_models import InputFormat
from docling.datamodel.pipeline_options import PdfPipelineOptions, RapidOcrOptions, TableFormerMode
from docling.document_converter import DocumentConverter, PdfFormatOption

opts = PdfPipelineOptions(do_ocr=True, do_table_structure=True)
opts.ocr_options = RapidOcrOptions(force_full_page_ocr=False) # Run OCR only on scanned regions
opts.table_structure_options.mode = TableFormerMode.ACCURATE  # Best fidelity for merged headers

converter = DocumentConverter(format_options={InputFormat.PDF: PdfFormatOption(pipeline_options=opts)})
doc = converter.convert("quarterly_report.pdf").document
print(doc.export_to_markdown()) # CLI VLM option: docling --pipeline vlm --vlm-model granite_docling file.pdf

Crawl4AI: Async Playwright, Pruning & Schema Extraction

Crawl4AI gives Python engineers direct programmatic control over headless Chromium instances—pairing concurrent crawling with heuristic Markdown noise pruning and deterministic CSS extraction schemas.

1Zero-LLM JsonCssExtractionStrategy

Map repeating DOM cards once using CSS or XPath selectors. Extracting 10,000 uniform catalog or directory pages costs zero LLM tokens and finishes deterministically in milliseconds.

2Schema-Guided LLMExtractionStrategy

When page HTML varies wildly, supply a Pydantic schema via LLMConfig and set input_format="fit_markdown" so the model only reads high-signal body text.

Crawl4AI Formula: Browser Env (BrowserConfig) + Noise Pruner (PruningContentFilter) + CSS / LLM Extract (extraction_strategy) + Wait & Session (wait_for, session_id) 
import asyncio, json
from crawl4ai import AsyncWebCrawler, BrowserConfig, CrawlerRunConfig, CacheMode
from crawl4ai.content_filter_strategy import PruningContentFilter
from crawl4ai.markdown_generation_strategy import DefaultMarkdownGenerator
from crawl4ai.extraction_strategy import JsonCssExtractionStrategy

async def scrape_catalog():
    md_gen = DefaultMarkdownGenerator(content_filter=PruningContentFilter(threshold=0.4, min_word_threshold=20))
    schema = {"name": "Posts", "baseSelector": "article.post", "fields": [
        {"name": "title", "selector": "h2", "type": "text"},
        {"name": "href", "selector": "a", "type": "attribute", "attribute": "href"},
    ]}
    run_cfg = CrawlerRunConfig(cache_mode=CacheMode.BYPASS, markdown_generator=md_gen,
        extraction_strategy=JsonCssExtractionStrategy(schema), wait_for="css:article.post")
    async with AsyncWebCrawler(config=BrowserConfig(headless=True)) as crawler:
        res = await crawler.arun(url="https://example.com/blog", config=run_cfg)
        return res.markdown.fit_markdown, json.loads(res.extracted_content or "[]")
PPruningContentFilter vs. BM25

PruningContentFilter scores DOM link density and text length to strip menus and footers across entire sites. Use BM25ContentFilter(user_query=...) when you only want blocks matching a specific search topic.

SStateful session_id & Lifecycle Hooks

Keep a single browser tab alive across pagination clicks by reusing session_id with js_only=True and js_code, and inject cookies or auth headers safely inside on_page_context_created.

Always Attach a Filter Before Reading fit_markdown
A frequent beginner pitfall is inspecting result.markdown.fit_markdown without passing a content filter to DefaultMarkdownGenerator—which leaves fit_markdown empty. Explicitly attach PruningContentFilter or BM25ContentFilter to unlock 60–80% boilerplate token reduction.

from pydantic import BaseModel

class PricingTier(BaseModel):

HybridChunker, Contextualization & Provenance Metadata

Clean Markdown is only half the ingestion pipeline. Naive character splitters tear apart Markdown tables and strip parent headings; structure-aware chunking preserves semantics and clickable citations.

Provenance Formula: Token Cap (max_tokens=512) + Heading Path (meta.headings) + Table Repeat (repeat_table_header) + Origin Anchor (page_no + source_url + sha256) 
import hashlib
from datetime import datetime, timezone
from docling.chunking import HybridChunker

chunker = HybridChunker(tokenizer="sentence-transformers/all-MiniLM-L6-v2", max_tokens=512, repeat_table_header=True)
records = []
for idx, chunk in enumerate(chunker.chunk(doc)):
    contextual_text = chunker.contextualize(chunk) # Automatically prepends parent section headings!
    page_no = chunk.meta.doc_items[0].prov[0].page_no if chunk.meta.doc_items else None
    records.append({
        "id": f"{doc_id}_{idx}", "text": contextual_text,
        "headings": chunk.meta.headings, "page_no": page_no,
        "source_url": source_uri, "sha256": hashlib.sha256(contextual_text.encode()).hexdigest(),
        "ingested_at": datetime.now(timezone.utc).isoformat(),
    })
1Why HybridChunker Beats Fixed Splits

Operating directly on DoclingDocument, HybridChunker merges tiny adjacent bullets, splits oversized sections along sentence boundaries using your embedding model tokenizer, and repeats table headers if large tables span chunks.

2Audit-Grade Citation Provenance

Calling chunker.contextualize(chunk) embeds parent headings right above the chunk body for vector search, while page_no and bounding coordinates let agents render exact page links in regulated workflows.

Recipe 2 Implementation: Resilient Concurrent Batch Crawl with Rate Limiter

import asyncio
from crawl4ai import AsyncWebCrawler, BrowserConfig, CrawlerRunConfig, CacheMode, RateLimiter
from crawl4ai.async_dispatcher import MemoryAdaptiveDispatcher
from crawl4ai.content_filter_strategy import PruningContentFilter
from crawl4ai.markdown_generation_strategy import DefaultMarkdownGenerator

async def batch_ingest_docs(urls: list[str]) -> dict[str, str]:
    dispatcher = MemoryAdaptiveDispatcher(memory_threshold_percent=75.0, max_session_permit=6,
        rate_limiter=RateLimiter(base_delay=(1.0, 2.0), max_delay=30.0, max_retries=3))
    run_cfg = CrawlerRunConfig(cache_mode=CacheMode.ENABLED,
        markdown_generator=DefaultMarkdownGenerator(content_filter=PruningContentFilter(threshold=0.45)))
    async with AsyncWebCrawler(config=BrowserConfig(headless=True, verbose=False)) as crawler:
        results = await crawler.arun_many(urls=urls, config=run_cfg, dispatcher=dispatcher)
        return {r.url: r.markdown.fit_markdown for r in results if r.success and r.markdown.fit_markdown}

Crawl Ethics, Prompt-Injection Quarantine & Deduplication

External websites and third-party PDFs are untrusted inputs. Production pipelines respect domain crawl rules, sanitize invisible adversarial instructions deterministically, and hash normalized text before embedding.

1Politeness & robots.txt

Check robots.txt rules before crawling, honor Crawl-delay and HTTP 429 Retry-After headers, send an identifiable User-Agent contact string, and cache repeat fetches cleanly.

2Prompt-Injection Defense

Attackers embed hijacks inside display:none elements, HTML comments, opacity:0 spans, or invisible Unicode tags (U+200B, U+E0000). Scrub them prior to chunking.

3SHA-256 & Near-Dedup

Canonicalize URLs (strip utm_* params), normalize whitespace, and skip identical SHA-256 hashes. Add MinHash or SimHash LSH to catch near-duplicate mirror pages.

Production Sanitizer, SHA-256 Deduplicator & Nonce Quarantine Wrapper

import hashlib, re, secrets, unicodedata
from bs4 import BeautifulSoup, Comment

INVISIBLE_RE = re.compile(r"[\u200b-\u200f\ufeff\u202a-\u202e\U000e0000-\U000e007f]")
HIDDEN_STYLE_RE = re.compile(r"(display\s*:\s*none|visibility\s*:\s*hidden|opacity\s*:\s*0|font-size\s*:\s*0)", re.I)

def sanitize_and_digest(raw_html: str) -> tuple[str, str]:
    soup = BeautifulSoup(raw_html, "html.parser")
    for tag in soup(["script", "style", "noscript", "template"]): tag.decompose()
    for c in soup.find_all(string=lambda t: isinstance(t, Comment)): c.extract()
    for hidden in soup.find_all(style=HIDDEN_STYLE_RE): hidden.decompose()
    clean = INVISIBLE_RE.sub("", unicodedata.normalize("NFKC", soup.get_text(" ", strip=True)))
    digest = hashlib.sha256(re.sub(r"\s+", " ", clean).strip().encode("utf-8")).hexdigest()
    return clean, digest

def frame_for_rag(clean_text: str, source_url: str) -> str:
    nonce = secrets.token_hex(8)
    return f'[UNTRUSTED_WEB_SOURCE url="{source_url}" nonce="{nonce}"]\n{clean_text}\n[/UNTRUSTED_WEB_SOURCE nonce="{nonce}"]'
UURL Canonicalization Rules

Normalize scheme and lowercase host, strip fragment anchors (#section), drop tracking parameters (utm_*, fbclid, gclid), and sort remaining query keys so identical pages never enter the crawl queue twice.

HExact Hash vs. Fuzzy Similarity

Use exact SHA-256 digests to skip byte-identical re-crawls at zero cost. Layer 128-permutation MinHash or SimHash LSH above that to collapse regional mirror pages that differ only by currency or timestamp banners.

Defense in Depth: Never Rely on System Prompts Alone
Telling an agent to ignore instructions found in scraped text fails whenever adversarial directives share the same token stream. Combine deterministic pre-ingestion DOM and Unicode sanitization with cryptographic nonce framing, output-schema checks, and strict sandbox egress controls so retrieved text remains inert data.

End-to-End Synergy Pipeline: Discovery to Verified RAG

Rather than forcing one engine onto every workload, production teams route web links, interactive portals, and binary attachments to specialized extractors before merging everything into one clean index.

1Hybrid Web + PDF Documentation Portals

Corporate knowledge portals constantly mix HTML pages with linked .pdf whitepapers and specification sheets. Configure Firecrawl /map or Crawl4AI to collect all links, route HTML pages through PruningContentFilter, and pass discovered .pdf and .docx URLs directly to Docling DocumentConverter so tables never flatten.

2Webhook-Driven Incremental Syncs

Rather than re-scraping and re-embedding your entire corpus nightly, attach Firecrawl changeTracking webhooks to trigger re-chunking only when changeStatus equals changed or new. Pair that gate with chunk-level SHA-256 hashing to skip unchanged paragraphs and cut embedding costs by over 80%.

MLive Agent Tooling

Expose firecrawl-mcp or Docling tools via MCP so coding agents pull fresh API docs and attachments on demand.

VHybrid Vector Search

Four Pipeline SLIs Every Ingestion Team Should Track
Measure four numbers on every run: (1) Extraction success rate across MIME types, (2) Markdown compression ratio comparing raw HTML to fit_markdown, (3) Quarantine strip count logging blocked hidden prompts, and (4) SHA-256 skip rate confirming incremental sync efficiency.

Troubleshooting Clinic & Pre-Flight Checklist

Rapid fixes for the seven most frequent document parsing and web scraping failure modes, paired with a mandatory six-point pre-flight check before launching production ingestion jobs.

Symptom & Error Root Cause 10-Second Production Fix
fit_markdown is empty string DefaultMarkdownGenerator initialized without a content filter. Attach PruningContentFilter(...) or BM25ContentFilter(...) to markdown_generator.
TableFormer scrambles merged columns Default FAST table mode missed multi-row or hierarchical headers. Set opts.table_structure_options.mode = TableFormerMode.ACCURATE or try VlmPipeline.
Scanned PDF outputs blank text File holds raster page images with no text layer and OCR is off. Enable do_ocr=True with RapidOcrOptions or MacOcrOptions (or force_full_page_ocr=True).
React / SPA scrape misses body Extractor read the DOM before client hydration or API fetch completed. Add wait_for="css:.article-body" in Crawl4AI or actions=[{"type": "wait", ...}] in Firecrawl.
arun_many triggers OOM crash Too many headless Chromium contexts opened concurrently on host RAM. Use MemoryAdaptiveDispatcher(memory_threshold_percent=75.0) and cap max_session_permit.
Firecrawl returns stale page content Firecrawl v2 defaults to a 2-day semantic cache window (maxAge). Pass max_age=0 on live price, inventory, or changelog checks that require fresh fetches.
Duplicate chunks pollute RAG Tracking query strings (?utm_source=) or unchanged re-crawls re-embedded. Strip marketing query params during URL canonicalization and skip identical SHA-256 digests.

6-Point Pre-Flight Ingestion Readiness Checklist

□ 1. Robots & Rate Limits Active: Verify robots.txt compliance, exponential backoff via RateLimiter on HTTP 429/503, and an honest User-Agent string.

□ 2. Boilerplate Pruning Verified: Sample raw HTML versus fit_markdown output to confirm navbars, cookie modals, and footers are stripped cleanly.

□ 3. Table & OCR Fidelity Tested: Run complex golden-set PDFs through TableFormerMode.ACCURATE and check numeric column alignment.

□ 4. Injection Sanitizer Armed: Test that display:none blocks, HTML comments, and U+200B tokens are removed and RAG context uses nonces.

□ 5. SHA-256 Dedup & Canonical URLs: Confirm normalized digests skip unchanged re-ingests and tracking query parameters are stripped.

□ 6. Provenance Metadata Populated: Check that every chunk in your vector database carries source_url, headings, page_no, and ingested_at.
