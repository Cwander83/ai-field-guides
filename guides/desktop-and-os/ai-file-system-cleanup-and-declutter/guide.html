04 • Cryptographic Deduplication SHA-256 Sweeps with rmlint, fdupes & Python hashlib

SHA-256 Duplicate Sweeps: Zero-Guesswork Cleanup

Filename heuristics fail in both directions: two different monthly statements might both arrive as statement.pdf, while an identical 200 MB installer lurks under Docker.dmg and Docker (1).dmg. Size pre-filtering followed by SHA-256 hashing finds true clones with mathematical certainty.

Size Bucket → SHA-256 Digest → Quarantine: Two files only reach full cryptographic hashing if their exact byte sizes match first, keeping scans blazingly fast across tens of gigabytes.

Three Proven Duplicate Sweep Engines

1 rmlint Script-First Sweep

Rather than deleting live files, rmlint writes a clean executable script (rmlint.sh). Run ./rmlint.sh -n first for a dry-run preview; pass -p if you want extra byte-by-byte verification alongside SHA-256.

2 fdupes Default Dry Run

Classic fdupes (or faster C fork jdupes) prints duplicate sets without touching disk unless you pass -d. Add -r -n -A -S to recurse while skipping empty 0-byte files and hidden .DS_Store metadata.

3 Python hashlib.file_digest

Available natively on both Mac and Windows in Python 3.11+, hashlib.file_digest(f, "sha256") streams huge video or ISO files at C speed without loading gigabytes into RAM.

4 Keep Canonical, Stage Clones

Always sort each duplicate cluster to keep the shortest clean path outside Downloads/ (or oldest original without (1)), routing remaining clones straight to _quarantine_30d/dupes/. 

# 1) rmlint SHA-256 sweep (macOS / Linux / WSL2) -- generates rmlint.sh without touching files, then dry-run:
rmlint --algorithm=sha256 --types="duplicates" --output=sh -p ~/Downloads ~/Desktop && ./rmlint.sh -n

# 2) fdupes safe read-only report (skips 0-byte files -n and hidden dotfiles like .DS_Store -A):
fdupes -r -n -A -S ~/Downloads > ~/Desktop/dupes_preview.txt

# 3) Cross-OS Python 3.11+ SHA-256 hash helper (streams chunks cleanly at C speed):
python3 -c 'import hashlib, pathlib; print(hashlib.file_digest(open("invoice.pdf","rb"), "sha256").hexdigest())'
Smart Original Selection Rule: Never Let Random Order Pick the Survivor
When deduplicating across ~/Documents and ~/Downloads, list your organized archive folder before ~/Downloads on the CLI (or mark it as a tagged keeper with rmlint ... // ~/Documents) so copies in Downloads are staged instead of filed originals.

The 5-Part Safe Cleanup & Manifest Formula

Whether you write a Python cleanup script, configure a PowerShell audit, or prompt Claude Cowork and Gemini CLI, reliable file automation separates deterministic rules from AI judgment using five non-negotiable building blocks.

Deterministic Layer (Scripts & OS Tools)
  • Exact Extensions & Paths: Moving .dmg/.exe installers, filtering node_modules/, and checking file age (>30 days).
  • Cryptographic Checksums: Computing SHA-256 hashes and verifying post-move byte integrity.
  • Quarantine & Undo: Writing deterministic CSV rollback ledgers before moving any file.
Semantic AI Layer (Cowork, Gemini, VLMs)
  • Fuzzy Document Triage: Distinguishing a signed NDA from a draft slide deck or utility receipt.
  • OCR & Screenshot Naming: Reading vendor logos and dates inside flattened PDFs and PNG screenshots.
  • Folder Proposal: Clustering 400 random downloads into 5–6 clean, domain-specific folders.

The 5-Part Guarded Declutter Formula

[1. Strict Scope] Target only ~/Downloads & ~/Desktop, [2. Exclusion Guard] skip .DS_Store, node_modules, .git & *.crdownload, [3. Hash & Schema] compute SHA-256 + YYYY-MM-DD_Vendor_Category names, [4. Dry-Run Manifest] write manifest.csv & pause for approval, [5. 06 • Intelligent PDF Renaming OCR Text Layers, VLMs & Invoice Naming

VLM & OCR Receipt Renaming: End Scan_042.pdf Chaos

Generic filenames like document(3).pdf, IMG_4821.HEIC, or Screenshot 2026-11-04.png bury tax deductions and receipts under unsearchable timestamps. Combining lightweight OCR with Vision-Language Models (VLMs) extracts clean metadata into universal YYYY-MM-DD_Vendor_Category.pdf sorting.

1 Text Layer vs. VLM

Digital invoices already contain selectable text. Scanned receipts lack text layers: run ocrmypdf --deskew --skip-text first, or inspect page 1 directly with a VLM (Claude, Gemini, or local qwen-vl).

2 Strict Filename Schema

Lock output to YYYY-MM-DD_Vendor_Category.pdf. Strip spaces, commas, slashes, and corporate suffixes (Inc, LLC) so filenames sort chronologically across Finder, Explorer, and terminal shells.

3 Low-Confidence Fallback

If a blurry receipt returns missing dates or illegible totals, never guess: move it to _needs_review/ or stamp file mtime with _REVIEW so your tax archive stays 100% trustworthy.

09 • Quarantine & Rollback Safety _quarantine_30d/ Cooling-Off Vault, Undo Logs & AI Privacy

Quarantine Staging, Privacy & Instant Rollback Safety

Real peace of mind comes from knowing every automated cleanup decision is completely reversible. By parking flagged items in a dated _quarantine_30d/ holding bay with an undo ledger—and keeping sensitive tax or health PDFs local—you eliminate catastrophic mistakes.

1 The _quarantine_30d/ Cooling-Off Protocol
  • Dated Staging Batches: Move old installers, empty folders, and SHA-256 duplicates into _quarantine_30d/YYYY-MM-DD/ instead of running rm or Remove-Item.
  • Machine-Readable Undo Ledger: Log every moved item in rollback_manifest.csv with timestamp, sha256, original_path, and quarantine_path.
  • 30-Day Purge Gate: Only empty batches older than 30 days after verifying you still have a recent Time Machine, Windows File History, or cloud backup snapshot.
2 Sensitive PDF & Metadata Privacy
  • Keep PII Local First: Never upload unredacted tax forms, bank statements, passports, or medical records to consumer AI chats with training enabled.
  • Local OCR + Local Vision: Use offline ocrmypdf, Hazel 6, or a local Ollama model for sensitive receipts, reserving cloud prompts for zero-retention/enterprise plans.
  • Strip GPS Before Sharing: Before archiving or sharing phone photos, strip EXIF location coordinates using macOS Preview/Shortcuts or PowerShell/ExifTool.

# One-command Python Rollback (reads rollback_manifest.csv, verifies SHA-256, restores every file):
import csv, hashlib, shutil, pathlib
for row in reversed(list(csv.DictReader(open("_quarantine_30d/rollback_manifest.csv")))):
    q, orig = pathlib.Path(row["quarantine_path"]), pathlib.Path(row["original_path"])
    if q.exists() and hashlib.file_digest(q.open("rb"), "sha256").hexdigest() == row["sha256"]:
        orig.parent.mkdir(parents=True, exist_ok=True); shutil.move(str(q), str(orig))

Troubleshooting Clinic & 6-Point Pre-Flight Checklist

Reach for this clinic whenever .DS_Store floods a duplicate report, scanned PDFs refuse to rename, active browser downloads get moved prematurely, or Hazel skips cloud placeholders—followed by our 6-point pre-flight checklist.

Symptom / Issue Root Cause 10-Second Fix
1. Scanner choked on 180,000 tiny code files Cleanup script traversed node_modules/, .git/, .venv/, or target/. Add an early directory prune guard skipping SKIP_DIRS before entering subdirectories or hashing any files.
2. Duplicate list full of .DS_Store & Thumbs.db Hidden OS folder-layout metadata files share identical default byte headers. Pass -A (--nohidden) to fdupes, exclude dotfiles in rmlint, and filter .DS_Store / desktop.ini upfront.
3. Browser download corrupted mid-transfer Folder watcher moved a .crdownload, .part, or .download temp file too early. Exclude active partial-download extensions and add a rule requiring modified age > 5 minutes before sorting.
4. Scanned receipt stayed Scan_042.pdf Image-only scan lacked an embedded text layer for regex or text tools to read. Run ocrmypdf --deskew --skip-text first, enable Hazel 6 on-the-fly OCR, or pass page 1 to a Vision model.
5. PowerToys PowerRename skipped subfolders Launched only on top-level selection, or regex didn’t match target scope dropdown. Expand subfolders inside Explorer search view, check Use regular expressions, or use PowerShell Get-ChildItem -Recurse -WhatIf.
