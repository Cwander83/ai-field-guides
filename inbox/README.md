# `inbox/` — Drop Folder for New & Existing Guides

Drop any raw material you want transformed into a 12-page visual field manual right into this folder:

- Existing Markdown guides, Obsidian notes, or SOPs
- Exported PDFs or slide decks you want redesigned into the series format
- Screenshots, rough bullet outlines, or product URLs

### How to Convert a Draft
Ask your coding agent:
> *"Convert `inbox/<filename>` into a new visual field guide under `guides/<ecosystem>/<slug>` following `AGENTS.md`."*

*(Keep this `README.md` in place so the `inbox/` directory stays tracked in Git.)*
